# 糯米贴贴 · Nuomi Sticker Studio

[在线使用 / Try it online](https://xuan-boms.github.io/nuomi-sticker/) · [GitHub 仓库 / Repository](https://github.com/Xuan-BOMS/nuomi-sticker)

一个用于给图片添加透明贴纸的轻量网页工具。选择下江小春等贴纸，拖动、缩放、旋转后即可导出 PNG。

A lightweight web tool for adding transparent stickers to images. Choose a sticker, drag, scale, and rotate it, then export the result as a PNG.

## 功能 Features

- 拖放、选择或粘贴图片 / Drag, choose, or paste an image
- 内置四种贴纸，也支持上传自定义透明贴纸 / Four built-in stickers plus custom transparent stickers
- 拖动、缩放、旋转、镜像、居中和复制 / Move, scale, rotate, flip, center, and duplicate
- 支持电脑和手机，手机可单指拖动、双指缩放与旋转 / Works on desktop and mobile, with one-finger dragging and two-finger zooming or rotation
- 本地处理，无需登录或上传服务器 / Processes images locally without login or server upload
- 按原图尺寸导出 PNG / Export PNG at the original image size

## 使用方法 How to use

1. 打开[在线工具](https://xuan-boms.github.io/nuomi-sticker/)，导入一张图片。  
   Open the [online tool](https://xuan-boms.github.io/nuomi-sticker/) and import an image.
2. 选择贴纸并调整位置、大小和角度。  
   Choose a sticker and adjust its position, size, and angle.
3. 点击“保存图片”下载合成后的 PNG。  
   Click “保存图片 / Save image” to download the composited PNG.
